Label-DP input perturbation is indirect

Label noise under label-DP (\(X\) public, \(y\) private) is a real but narrow model — not the main row-DP contract. Input perturbation wastes budget: sensitivity \(2\) per label vs \(2/n\) for the statistic.

Input/output foils fail for geometric reasons

Feature perturbation and output perturbation are diagnostics only under row-DP — not comparable repairs without a full mechanism spec.

\(A=X^\top X\), \(b=X^\top y\): the repair target

Under row-DP, both sufficient statistics are private. The repair family releases noisy substitutes \((\tilde A, \tilde b)\) then solves ridge regression.

AdaSSP and Gram-sketch repair

Two row-DP repairs in the same sufficient-statistics interface:

  • AdaSSP — perturb \(A\) and \(b\) directly.
  • Gram-sketch repair — sketch/mix the Gram side, noise the RHS.

Note

The Gram-sketch repair here is a local teaching implementation of a one-step Hessian-mixing idea. It is regression-tested for fixed seeds, but it is not presented as a fully audited upstream port.
